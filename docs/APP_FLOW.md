# APP_FLOW.md — 应用流程文档

## 1. 系统架构概览

```
用户浏览器 ←→ FastAPI 后端 ←→ Python 推理引擎 ←→ 摄像头 MJPEG 流

通信方式:
  浏览器 ↔ 后端:   HTTP (页面/静态资源) + MJPEG (视频流) + WebSocket (统计数据)
  后端 ↔ 推理引擎:  Python 内存共享 (同一个进程)
  推理引擎 ↔ 摄像头: HTTP MJPEG (局域网 WiFi)
```

## 2. 页面清单

本系统为**单页面应用 (SPA)**，只有一个核心页面：

| 页面 | 路由 | 描述 |
|------|------|------|
| 监控仪表盘 | `/` | 实时视频 + 统计面板 + 告警叠加 |

#### 3.1.3 状态变化触发条件

| UI 元素 | 正常状态 | 告警状态 | 触发条件 |
|---------|---------|---------|---------|
| 未戴安全帽数字 | 绿色数字 `0` | 红色数字 + 黄色背景闪烁 | WebSocket 推送 `no_helmet > 0` |
| 未穿反光衣数字 | 绿色数字 `0` | 红色数字 + 黄色背景闪烁 | WebSocket 推送 `no_vest > 0` |
| 摔倒状态 | 绿色 "正常" | 红色 "⚠ 触发" + 视频叠加警告 | WebSocket 推送 `fall: true` |
| 系统状态灯 | 绿色 "● 运行中" | 红色 "● 告警中" | 任一违规触发 |
| 视频区 AlertOverlay | 隐藏 | 显示 "⚠ 摔倒警告" 红色大字（闪烁） | WebSocket 推送 `fall: true` |

## 4. 用户导航流程

```

    ▼

               ▼
┌─────────────────────────────────────┐
│ 2. 推理引擎初始化                    │
│    - 加载 YOLO 检测模型              │
│    - 加载 YOLO 姿态模型              │
│    - 初始化 pygame 音频              │
│    - 加载告警音文件                  │
└──────────────┬──────────────────────┘

               ▼

│ 3. 连接摄像头                        │
│    cv2.VideoCapture(MJPEG_URL)       │
│    ├─ 成功 → 继续                    │

               ▼

│    读帧 → 检测 → 姿态 → 绘图 → 推送   │
```

### 4.2 正常运行态 → 安全违规告警流程

```
[正常运行态: 所有人佩戴安全帽、穿反光衣]
    │
    │ 某人摘下安全帽进入画面
    ▼
┌─────────────────────────────────────────────┐
│ 推理引擎检测到 "person_no_helmet" 类别         │
│ （单帧检出，尚未触发告警）                     │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ 告警状态机: 连续违规帧计数 +1                 │
│ 当前计数: 1/3（尚未达到触发阈值）             │
│ → 视频帧已经开始绘制红色框                    │
└──────────────┬──────────────────────────────┘
               │
               │ 第 2 帧: 连续计数 = 2
               │ 第 3 帧: 连续计数 = 3
               ▼
┌─────────────────────────────────────────────┐
│ 告警状态机: 达到触发阈值 (≥3帧)              │
│ → alarm.play("alarm1") 开始循环播放（幂等）   │
│ → 状态切换: [静默] → [播放中]                │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ WebSocket 推送 stats 到前端                  │
│ { "no_helmet": 1, "total": 5, ... }          │
│ （推送频率: 5-10 Hz，非每帧）                 │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ 前端 StatsPanel 更新:                        │
│ - "未戴安全帽" 数字变为红色 1                 │
│ - 该卡片背景变为淡红色                        │
│ - 顶部系统状态灯变为红色 "● 告警中"           │
└─────────────────────────────────────────────┘
               │
               │ 违规持续: 告警音循环播放
               │ 每 100-200ms WebSocket 推送
               │
               │ 该人戴上安全帽
               ▼
┌─────────────────────────────────────────────┐
│ 推理引擎: no-helmet 消失                     │
│ 告警状态机: 连续正常帧计数 +1                 │
│ 当前计数: 1/5（尚未达到解除阈值）             │
└──────────────┬──────────────────────────────┘
               │
               │ 第 5 帧: 连续计数 = 5
               ▼
┌─────────────────────────────────────────────┐
│ 告警状态机: 达到解除阈值 (≥5帧)              │
│ → alarm.stop("alarm1") 停止播放              │
│ → 状态切换: [播放中] → [静默]                │
│ → WebSocket 推送 { "no_helmet": 0, ... }     │
│ → 前端数字恢复绿色 0，卡片背景恢复            │
│ → 系统状态灯恢复绿色 "● 运行中"              │
└──────────────┬──────────────────────────────┘
               │
               ▼
          [恢复正常运行态]
```

```
[正常运行态]
    │
    │ 画面中有人摔倒
    ▼
┌─────────────────────────────────────────────┐
│ 姿态估计: is_fallen(keypoints, bbox) → True  │
│ （单帧检出，尚未触发告警）                     │
│ 统计: stats.fall 仍为 false                   │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ 摔倒状态机: 连续摔倒帧计数 +1                 │
│ 当前计数: 1/3（尚未达到触发阈值）             │
│ → 视频帧已经开始绘制 "⚠ FALL" 标记           │
└──────────────┬──────────────────────────────┘
               │
               │ 第 2 帧: 连续计数 = 2
               │ 第 3 帧: 连续计数 = 3
               ▼
┌─────────────────────────────────────────────┐
│ 摔倒状态机: 达到触发阈值 (≥3帧)              │
│ stats.fall 变为 true                          │
│ → alarm.play("alarm2") 开始循环播放（幂等）   │
│ → 状态切换: [正常] → [摔倒告警中]            │
│ → WebSocket 推送 { "fall": true, ... }       │
│   （推送频率: 5-10 Hz）                       │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ 前端响应:                                    │
│ - AlertOverlay 显示 "⚠ 摔倒警告" 红色大字    │
│   (CSS 动画: 闪烁)                           │
│ - "摔倒检测" 卡片变红 + "⚠ 触发"             │
│ - 系统状态灯变红                              │
└─────────────────────────────────────────────┘
               │
               │ 摔倒持续: 告警音循环播放
               │
               │ 人员站起
               ▼
┌─────────────────────────────────────────────┐
│ 姿态估计: is_fallen() → False                │
│ 摔倒状态机: 连续正常帧计数 +1                 │
│ 当前计数: 1/5（尚未达到解除阈值）             │
└──────────────┬──────────────────────────────┘
               │
               │ 第 5 帧: 连续计数 = 5
               ▼
┌─────────────────────────────────────────────┐
│ 摔倒状态机: 达到解除阈值 (≥5帧)              │
│ stats.fall → false                           │
│ → alarm.stop("alarm2")                       │
│ → 状态切换: [摔倒告警中] → [正常]            │
│ → AlertOverlay 隐藏                          │
│ → 卡片恢复绿色 "正常"                        │
│ → 系统状态灯恢复绿色 "● 运行中"              │
└──────────────┬──────────────────────────────┘
               │
               ▼
          [恢复正常运行态]
```

### 4.4 异常流程

#### 4.4.1 摄像头断连

```
[正常运行态]
    │
    │ 摄像头断连 (WiFi 断开/摄像头断电)
    ▼
┌─────────────────────────────────────────────┐
│ cv2.VideoCapture.read() 返回 (False, None)   │
│ → 捕获异常，不崩溃                            │
│ → 最后成功帧继续推流（画面冻结）               │
│ → WebSocket 推送 { "camera_status": "disconnected" } │
│ → 前端 "摄像头状态" 变为 "● 断连中" (红色)    │
│ → 终端打印: "[WARN] 摄像头断连，3秒后重试..." │
│ → 推理管线暂停处理，等待重连                   │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│ 每 3 秒尝试 cv2.VideoCapture(MJPEG_URL)      │
│ ├─ 重连成功 → 恢复正常运行                    │
│ └─ 重连失败 → 继续重试                        │
└─────────────────────────────────────────────┘
```

#### 4.4.2 模型加载失败

```
[系统启动]
    │
    │ 队友模型 helmet_vest.pt 不存在
    ▼
┌─────────────────────────────────────────────┐
│ 检测到 models/helmet_vest.pt 缺失             │
│ → 终端打印: "[WARN] 队友模型未找到，          │
│   使用 YOLOv8n COCO 预训练模型作为占位"       │
│ → 自动回退到 yolov8n.pt                      │
│ → 仅检测 COCO "person" 类（无安全帽/反光衣）  │
│ → 系统继续运行，功能降级但不崩溃               │
└─────────────────────────────────────────────┘
```

#### 4.4.3 告警音频文件缺失

```
[系统启动]
    │
    │ alarms/alarm1.mp3 或 alarm2.mp3 缺失
    ▼
┌─────────────────────────────────────────────┐
│ → 终端打印: "[WARN] 告警音频文件不存在:       │
│   alarms/alarm1.mp3，告警音将被禁用"         │
│ → 检测和统计功能正常                          │
│ → 前端告警显示正常                            │
│ → 仅音频播放被跳过                            │
└─────────────────────────────────────────────┘
```

## 5. WebSocket 消息协议

### 5.1 消息格式

所有 WebSocket 消息为 JSON 格式：

```json
{
  "type": "stats",
  "data": {
    "total_persons": 5,
    "no_helmet": 2,
    "no_vest": 1,
    "fall": true,
    "camera_status": "connected",
    "fps": 24.5,
    "timestamp": "2026-07-13T14:30:25.123456"
  }
}
```

### 5.2 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `total_persons` | int | 画面中检测到的总人数 |
| `no_helmet` | int | 未佩戴安全帽的人数 |
| `no_vest` | int | 未穿反光衣的人数 |
| `fall` | bool | 是否检测到摔倒 |
| `camera_status` | string | `"connected"` 或 `"disconnected"` |
| `fps` | float | 当前推理帧率 |
| `timestamp` | string | ISO 8601 时间戳 |

## 6. HTTP API 路由

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 前端 SPA 入口页面 |
| GET | `/stream/video` | MJPEG 视频流（带 YOLO 标注框） |
| WS | `/ws/stats` | WebSocket 统计数据推送 |
| GET | `/api/health` | 健康检查：返回 `{"status": "ok"}` |

## 7. 用户关闭流程

```
用户在浏览器关闭标签页
    │
    ▼
WebSocket 连接自动断开 (前端无操作)

用户在终端按 Ctrl+C
    │
    ▼
┌─────────────────────────────────────────────┐
│ KeyboardInterrupt 捕获                       │
│ → 推理管线停止                               │
│ → 释放摄像头资源 (cap.release())              │
│ → 停止所有告警音                              │
│ → 关闭 WebSocket 连接                        │
│ → 关闭 FastAPI 服务                          │
│ → 终端打印: "系统已停止"                      │
└─────────────────────────────────────────────┘
```
